# Ecosystem directory and network

LifeTech owns the static ecosystem directory. The relationship graph, layout, public snapshots, sourced event-history pipeline, and evidence tests belong to sibling OrgPortal. See [the shared data guide](../../OrgPortal/docs/ecosystem-network-data.md). `/ecosystem/network` and `/ecosystem-data/` are routed to the shared portal; this repository does not build or deploy a graph bundle.
